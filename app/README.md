# NEBULA — минималистичный магазин мебели

Тёмный одностраничный магазин с мгновенной фильтрацией, живым поиском и корзиной — **без бэкенда и без сборки**. Чистый HTML / CSS / JS, всё работает в браузере.

![stack](https://img.shields.io/badge/stack-HTML%20%C2%B7%20CSS%20%C2%B7%20JS-7c3aed)

## Фишки

- **Мгновенная фильтрация** по категориям — с плавным fade-out / fade-in, без перезагрузки.
- **Живой поиск** с debounce и транслитерацией: «атлас» найдёт «Диван Atlas».
- **Корзина** — выезжающая панель справа: количество, изменение qty, сумма, сохранение в `localStorage`.
- **Микро-взаимодействия**: товар «улетает» в корзину, бейдж пульсирует, карточки поднимаются при наведении и появляются со stagger-задержкой.
- **Дизайн-система**: CSS-переменные, сетка на `auto-fill minmax`, один акцентный цвет (`#7c3aed`), отступы кратны 8, единый easing `cubic-bezier(0.4,0,0.2,1)`.
- **Адаптив**: от десктопа 1280px до мобильного (2 колонки карточек, полноэкранная корзина).
- **Единая предметная съёмка**: все 20 фото приведены к одному тёмному студийному стилю с фиолетовым контровым светом.

## Структура

```
├── index.html      # разметка
├── styles.css      # дизайн-система и все стили
├── script.js       # каталог, фильтры, поиск, корзина
├── data.js         # массив из 20 товаров
└── assets/img/     # фото товаров (1024×1024)
```

## Запуск

Это статика — достаточно открыть `index.html` или поднять любой статический сервер:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## Деплой на GitHub Pages

```bash
git init && git add . && git commit -m "NEBULA store"
git remote add origin <ваш-репозиторий>
git push -u origin main
# Settings → Pages → Deploy from branch → main / root
```

## Технические детали

- Данные подключены через `data.js` (а не `fetch` к JSON), чтобы магазин работал и по `file://`, и на Pages.
- Состояние корзины переживает перезагрузку (`localStorage`, ключ `nebula_cart`).
- Учтён `prefers-reduced-motion`: анимации отключаются для пользователей с такой настройкой.
