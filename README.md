# NEBULA — минималистичный магазин мебели

Тёмный одностраничный магазин с мгновенной фильтрацией, живым поиском, корзиной, модальными карточками товаров и демо-админкой управления каталогом.

## Фишки

- **Мгновенная фильтрация** по категориям — с плавным fade-out / fade-in, без перезагрузки.
- **Живой поиск** с debounce и транслитерацией: «атлас» найдёт «Диван Atlas».
- **Модальные карточки товаров** — клик по любой карточке открывает полноэкранное окно с фото, описанием, материалами, размерами и кнопкой покупки.
- **Корзина** — выезжающая панель справа: количество, изменение qty, сумма, сохранение в `localStorage`.
- **Демо-админка** — отдельная страница `/admin.html`: таблица товаров с поиском, редактирование, добавление, удаление, сброс к заводским настройкам. В демо-режиме данные хранятся в `localStorage` (изменения видны только в текущем браузере).
- **Микро-взаимодействия**: товар «улетает» в корзину, бейдж пульсирует, карточки поднимаются при наведении и появляются со stagger-задержкой.
- **Дизайн-система**: CSS-переменные, сетка на `auto-fill minmax`, единый акцентный цвет (`#7c3aed` — фиолетовый), отступы кратны 8, единый easing `cubic-bezier(0.4,0,0.2,1)`.
- **Адаптив**: от десктопа 1280px до мобильного (2 колонки карточек, полноэкранная корзина, модалка в одну колонку).
- **Единая предметная съёмка**: все 20 фото приведены к одному тёмному студийному стилю.

## Структура
├── index.html      # разметка магазина (включая модальное окно товара и корзину)
├── admin.html      # панель администратора: таблица, CRUD, статистика
├── styles.css      # дизайн-система, тёмная тема, стили модалки и админки
├── script.js       # каталог, фильтры, поиск, корзина, модальные окна
├── data.js         # массив из 20 товаров с описаниями
└── assets/img/     # фото товаров (1024×1024)
